# Bdjobs.com Website Testing Project

## Project Overview
**Project Name:** Bdjobs.com Website Functional Testing  
**Date:** March 2024  

This repository contains testing documentation for **Bdjobs.com**, Bangladesh's first and leading career management platform. The project focused on ensuring that the website's core functionalities work correctly, user interactions are smooth, and all features meet requirements.

---

## Key Responsibilities
- Developed and maintained **Test Plans, Test Scenarios, and Test Cases** for main website features including user registration, login/logout, job search, job application, resume upload, and profile management.  
- Performed **Smoke Testing, Regression Testing, UI/Functionality Testing, and Exploratory Testing** across multiple browsers (Chrome, Firefox, Edge).  
- Reported defects with clear reproduction steps, screenshots, and tracked resolutions using **Jira**.  
- Collaborated with developers and server administrators to verify fixes and ensure deployment readiness.

---

## Tools & Environment
- **Testing Tools:** Microsoft Excel, Word  
- **Browsers:** Google Chrome, Firefox, Edge  
- **OS:** Windows 11   

---

## Achievements / Highlights
- Validated all critical user flows and UI elements on Bdjobs.com.  
- Ensured all reported defects were documented, tracked, and resolved prior to project closure.  
- Applied structured **Equivalence Class Partitioning, Boundary Value Analysis, Decision Table Testing, and Exploratory Testing techniques** for comprehensive coverage.
